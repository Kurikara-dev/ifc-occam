# クイックスタート (インストール不要・ダウンロードして使う)

このページは、プログラミングやコマンド操作をしたことがない方向けの手引きです。
Python のインストールも、コマンド入力も要りません。zip をダウンロードして、
ダブルクリックで起動するところから、軽くした IFC ファイルを保存するところまでを
順番に説明します。

用意するものは2つだけです。

- Windows の PC
- 軽くしたい `.ifc` ファイル

先にひとつだけ。このツールは**元のファイルを書き換えません**。出力されるのは
別名の新しいファイルで、あくまで閲覧用です。設計や施工の判断は必ず元のファイルで
行ってください。

## 1. ダウンロードする

1. [ダウンロードページ (Releases)](https://github.com/Kurikara-dev/ifc-occam/releases/latest) を開きます。
2. ページ内の **Assets** にある `ifc-occam-windows-v〇〇〇.zip` (約95MB) をクリックして
   ダウンロードします。
3. ブラウザによっては「一般的にダウンロードされているファイルではありません」の
   ような警告が出ます。このソフトが署名なしで配布されているためで、警告メニューから
   「保存」「継続」「保持する」を選べばダウンロードできます。

## 2. 展開する (zip のままでは動きません)

1. ダウンロードした zip ファイルを**右クリック**して「**すべて展開**」を選びます。
2. 展開先はデスクトップなど、自分が分かる場所ならどこでも構いません。
3. 展開すると `ifc_occam` というフォルダができ、その中に `ifc_occam.exe` が
   入っています。

zip をダブルクリックして中身をそのまま開いた状態で `ifc_occam.exe` を実行すると
動きません。必ず「すべて展開」をしてから使ってください。

## 3. IFC ファイルを置く

軽くしたい `.ifc` ファイルを、**`ifc_occam.exe` と同じフォルダの中にコピー**して
ください。

これは手抜きの説明ではなく仕様です。このツールの画面から選べるのは、起動した
フォルダの中にあるファイルだけです (PC 内のほかの場所を勝手に覗かない作りに
してあります)。フォルダの中にサブフォルダを作って、その中に置いても大丈夫です。

## 4. 起動する

1. `ifc_occam.exe` をダブルクリックします。
2. 「**Windows によって PC が保護されました**」という青い画面が出たら、
   「**詳細情報**」をクリックし、出てきた「**実行**」ボタンを押してください。
   これも署名なし配布による警告で、初回だけ出ます。
3. 黒いウィンドウが開き、続いてブラウザで操作画面が自動的に開きます。
   **初回はウイルススキャンが走るため、開くまで数分かかることがあります。**
   2回目からは数秒です。
4. **黒いウィンドウは閉じないでください。** これが本体で、閉じると操作画面も
   使えなくなります。邪魔なら最小化してください。

ブラウザが自動で開かない場合は、黒いウィンドウに表示されている
`http://127.0.0.1:8000/` のような文字をブラウザのアドレス欄に打ち込んでください。

## 5. ファイルを読み込んで軽くする

![操作画面の全体像。左にクラス別の一覧、右に3D表示](images/gui-overview.png)

1. 画面左上の「**ファイル指定**」ボタンを押すと、手順3で置いたファイルが一覧に
   出ます。クリックして選び、「選択」を押します。
2. 「**読込**」ボタンを押します。読込にかかる時間の目安が先に表示されるので、
   それを見てから押してください。大きいファイルでは数分かかります。
3. 読み込みが終わると、左の一覧に「どの種類の部材が、どれだけ表示を重くして
   いるか」が重い順に並びます。右の 3D 表示で実物を確認できます。
4. 一覧の行にマウスを乗せると「削除」「軽量化」などのボタンが現れます。
   たとえばボルトのような細かい部材の行で「削除」を押す、という操作を
   何回か繰り返します。行をクリックすると、その部材が 3D 表示で光るので、
   消してよいものか目で確かめられます。
5. 操作はすぐには実行されず「操作リスト」に溜まります。間違えてもこの時点では
   何も起きていないので、リストから取り消せます。
6. 「**出力**」に進み、保存する名前を付けて実行します。元のファイルと同じ名前は
   付けられないようになっています。

できあがった新しい `.ifc` ファイルが軽量版です。元のファイルはそのまま残って
います。

画面の細かい説明 (3D 表示の回し方、レイヤー別の操作、操作パターンの保存など) は
[操作ガイド](testing-guide.md) にあります。

## 6. 終了する

ブラウザのタブを閉じ、黒いウィンドウも閉じてください。以上です。
アンインストールしたくなったら、展開したフォルダごと削除すれば終わりです。
このツールは PC のほかの場所には何も書き込んでいません。

## うまくいかないとき

**ダブルクリックしても何も起きない / すぐ閉じる**
zip の中で直接実行していないか確認してください (手順2)。展開済みなら、
ウイルス対策ソフトが止めている可能性があります。社用 PC の場合は情報システム
部門に「署名なしの社外ツールを使いたい」と相談するのが早いです。

**ファイル一覧に自分の IFC ファイルが出てこない**
`.ifc` ファイルが `ifc_occam.exe` と同じフォルダ (またはその中のサブフォルダ) に
あるか確認してください。置き直したら、一覧を開き直せば出てきます。

**ファイルを選んだら警告色の案内が出た**
そのファイルはこの画面で扱うには大きすぎます (この警告が出るのは 2GB を超える
あたりからです)。このツールにはコマンド操作で使う大きいファイル向けのモード
(警告文中の「CUI」がそれです) があるので、社内の詳しい人に
[README](../README.ja.md) を渡して相談してください。警告ではなく単に
「推定読込時間が長い」だけなら、待てば読み込めます。

**画面がいつまでも「読込中」のまま**
数百 MB のファイルでは数分かかります。黒いウィンドウにエラーらしき赤い文字が
出ていなければ、待っていてください。

**軽量化したのに、できあがったファイルがむしろ大きくなった**
「間引き」や「凸包化」を選んだときにまれに起きます。この2つは、形をいったん
新しい三角形の集まりに描き直してから保存するため、見た目の三角形数が減っても
ファイルの中の記述量自体は増えてしまうことがあるからです。操作を選ぶと画面に
琥珀色の注意書きが出ることがあるので、まずそれを確認してください。そこに
理由と、代わりに試すとよい手法(「bbox」や「OBB」)が書かれています。手法ごとの
向き不向きは[操作ガイド](testing-guide.md)の「軽量化」の説明にまとめてあります。
